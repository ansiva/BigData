Tableau Submission README

For Tableau, we created two CSV files from the final Python output and prepared them for use in Tableau:

1. final_customer_decision_tableau.csv
   - Main Tableau-ready file
   - One row per customer
   - Used for customer engagement status, expected vs. latest cadence, assessed customers, and at-risk analysis

2. segment_summary_tableau.csv
   - Supporting Tableau-ready file
   - One row per basket x frequency segment
   - Used for segment-level comparison and additional Tableau analysis

We also created an optional Tableau dashboard using these files. The dashboard is included in the optional folder as an additional visualization of the project results.

For the Tableau extract itself, we were not able to download the extract from the Tableau version we were using. We used the public/free version available to us, so we are including an image showing the Tableau work along with the two Tableau-ready CSV files.

The two CSV files above are the final data files created specifically for Tableau and are included in this submission.

If you would like to review the Tableau extract or the Tableau work directly, we would be happy to show it in person, share it through email if possible, or find another appropriate way to provide access to it.

Thank you.
